# 🎉 Online Event Management System

A full-stack MERN application for managing events, registrations, attendance, and analytics with secure authentication and cloud deployment.

## 🚀 Features

- JWT Authentication
- Role-Based Access Control
- Event Management
- Event Registration
- QR Code Ticket Generation
- Attendance Tracking
- Email Notifications
- Dashboard Analytics
- Cloud Image Uploads
- Reports & Statistics

## 🛠 Tech Stack

### Frontend
- React
- Tailwind CSS
- Axios
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- JWT
- Bcrypt
- Nodemailer
- Cloudinary
